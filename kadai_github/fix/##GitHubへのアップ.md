\##GitHubへのアップ



‐1.ファイルを作成



‐2.git add \[ファイルパス]

‐全て追加したかったら、git add .



‐3.git commit -m "メッセージ"

‐何をコミットしているのかメモ



‐4.git status

‐コミットし損ねているものはないか状態を確認



‐5.git push -u \[接続先リモートリポジトリ] \[ローカルブランチ名]



\##プル

‐git pull \[対象のリモートリポジトリ] \[対象のブランチ名]

‐チーム作業をする際には、まずここからになるのではなかろうか



\##その他

‐ブランチにプッシュして、プルリクエストを行い、mainにマージという流れになる
